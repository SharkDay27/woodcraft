# 規劃：工作室生活、網路販售、工具與工作室升級

核心循環：

```
買木料 ──► 在工作室製作 ──► 拍照上架網路販售 ──► 賺錢、累積評價
   ▲                                              │
   └──── 買更好的工具／修繕工作室 ◄────────────────┘
```

設計原則（延續目前的寫實路線）：**每一項升級都要改變「物理」，而不是只改數字**。
好刨刀讓刃口更耐用、比較不顫刀；除濕機讓工坊的平衡含水率穩定；檯燈讓你更容易看清劃線。
金錢買到的是「更好控制木頭的能力」。

## 2. 網路販售

玩家用工作室裡的電腦（或手機）開一個「木作市集」網頁。

### 上架
1. 作品完成後，用遊戲內的相機拍照 → 照片就是商品縮圖（玩家自己布置、打光）
2. 自動帶出規格：樹種、尺寸、塗裝、評鑑分數
3. 玩家自己訂價

### 售價模型
```
參考價 = 材料成本 × 樹種溢價 + 工時價值 × 作品複雜度
期望售價 = 參考價 × 品質係數(評鑑分數) × 聲望係數 × 市場熱度
每天賣出的機率 = f(玩家訂價 / 期望售價)   ← 訂太貴就賣得慢
```
- **品質係數**直接用現有的評鑑分數：90 分以上的作品可以賣到參考價 1.5 倍以上
- **聲望**：買家評價累積而來，會提高期望售價與曝光度
- **市場熱度**：每週隨機輪替，例如「本週黑胡桃砧板很熱門」

### 兩種訂單
- **自由上架**：自己決定做什麼、賣多少錢
- **客製委託**：買家指定規格（樹種、尺寸、榫卯種類）與交期，報酬較高；做不到規格會被退件

### 延遲後果（寫實重點）
作品寄出後，系統會在幾天後依物理狀態判定結果：
- 組裝時含水率沒有平衡 → 到買家手上收縮，接合鬆動或開裂 → **退貨與負評**
- 塗裝沒乾就包裝 → 表面黏住包材 → 負評
- 接合強度太低 → 使用中鬆脫

讓玩家從市場回饋中**學到真實木工的道理**，而不是只看評分畫面。

## 3. 金錢用途

### 3-1 耗材（持續花費）
| 品項 | 寫實機制 |
|---|---|
| 木料 | 依樹種與乾燥方式計價；窯乾材貴、風乾材便宜但要放著等它乾 |
| 砂紙 | 會磨鈍：越用效率越差，要換新 |
| 白膠 | 有保存期限，過期強度下降 |
| 塗料 | 用一罐少一罐 |
| 替刃鋸片 | 日式替刃鋸鈍了是換刀片，不是自己磨 |

### 3-2 工具升級（每一階都改變物理參數）
| 工具 | 入門 | 中階 | 高階 |
|---|---|---|---|
| 刨刀 | 軟鋼刃：鈍得快、容易顫刀 | 高碳鋼：耐用 | 名匠鉋：有斷屑板，逆紋撕裂大幅降低 |
| 鋸 | 粗齒鋸：快但路寬 0.9mm | 兩刃鋸（目前預設） | 胴付鋸：鋸路 0.3mm、有背脊不易跑偏 |
| 鑿子 | 只有一支 12mm | 一組 6～18mm | 專用榫眼鑿：不易歪斜 |
| 磨刀石 | 只有 #1000 | 加 #6000 | 加 #220 荒砥 + 平面修正盤 |
| 量具 | 只有鋼尺（±0.5mm） | 游標卡尺（±0.05mm） | 數位卡尺 + **水分計**（沒有水分計就看不到含水率！） |
| F 夾 | 2 支 | 6 支 | 管夾：可以組裝大型家具 |

> 遊戲一開始故意只給入門工具：鑿寬、磨刀石、水分計都要賺錢買，這樣每次升級都很有感。

### 3-3 修繕工作室（改變環境）
| 升級 | 效果 |
|---|---|
| 除濕機／空調 | 把平衡含水率固定在 9%，不再受季節影響 |
| 更好的照明 | 夜晚劃線精度提升（光線不足時鉛筆線誤差加大） |
| 加大窗戶 | 白天光線更好，窗景更寬 |
| 木料架擴充 | 可以囤更多料、讓料慢慢適應濕度 |
| 集塵設備 | 砂磨粉塵減少；之後可加入「粉塵太多會影響塗裝品質」 |
| 夾背鉗（木工虎鉗） | 解鎖刨側邊、鋸鳩尾等需要固定工件的作業 |
| 裝潢擺設 | 純觀感：植物、收音機、海報、地毯（放鬆感的來源） |

## 4. 需要先補的系統

1. **作品系統**：目前只有一個 T 字接合練習件。要能販售，必須先把「作品」做成資料：
   `作品 = 零件清單 + 每個零件的目標尺寸 + 接合清單 + 評分規則`
   建議第一批作品：
   - **砧板**（最簡單：選料、刨平、修邊、砂磨、上食品級油）→ 新手第一個能賣的東西
   - **小木盒**（指接榫或鳩尾榫）
   - **四腳方凳**（多組方榫 + 方正檢查）
2. **GameState 單例**：金錢、庫存、擁有的工具、升級、聲望、日曆、訂單
3. **存檔／讀檔**：用 JSON 存在 `user://save.json`
4. **工作室內的互動物件**：電腦（市集）、木料架（買料、取料）、工具牆（換工具）、行軍床（睡覺）
